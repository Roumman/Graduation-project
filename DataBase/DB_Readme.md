# README

## Описание проекта

Проект представляет собой систему управления банковской базой данных на основе SQLite. Включает скрипты для создания, заполнения и обслуживания базы данных, а также SQL‑триггеры для автоматизации бизнес‑логики.

## Скрипты в папке `scripts`

### 1. `clear_database.py`

**Назначение:** полная очистка всех таблиц в базе данных `Bank_DB.db`.

**Функции:**
* `clear_all_tables()` — очищает таблицы: `account_transaction`, `loan`, `deposit`, `account`, `user_login`, `client`.
* Отключает проверку внешних ключей (`PRAGMA foreign_keys = OFF`) перед очисткой.
* Обрабатывает ошибки при удалении данных из каждой таблицы.
* Включает проверку внешних ключей обратно (`PRAGMA foreign_keys = ON`).

**Использование:**
```bash
python scripts/clear_database.py
```
### 2. create_and_populate.py

**Назначение:** создание структуры базы данных банковской системы и заполнение её тестовыми данными.

**Функции:**

- `create_bank_database(db_path)` — создаёт все таблицы БД:

- `client` — клиенты;

- `user_login` — логины и пароли;

- `account` — счета;

- `account_transaction` — транзакции;

- `loan` — кредиты;

- `deposit` — депозиты;

- `payment_schedule` — график платежей;

- `account_statement` — выписки по счёту;

- `interest_calculation` — расчёт процентов.

- `populate_database(conn)` — заполняет БД тестовыми данными (10 клиентов, счета, транзакции, кредиты, депозиты).

Вспомогательные функции:

- `hash_password(password)` — хеширование пароля (SHA‑256);

- `generate_account_number()` — генерация номера счёта;

- `create_payment_schedule_for_loan()` — график платежей по кредиту;

- `create_payment_schedule_for_deposit()` — график начисления процентов по депозиту.

### 3. generate_test_data.py ### 
**Назначение:** генерация тестовых данных для заполнения базы данных.

**Функции:

Генерация данных клиентов: имя, фамилия, отчество, телефон, email, адрес, дата рождения.

Создание уникальных логинов (generate_unique_username).

Заполнение таблиц: client, user_login, account, account_transaction, loan, deposit.

Использование тестовых наборов данных (FIRST_NAMES, LAST_NAMES и т. д.).

Использование:

```bash
python scripts/generate_test_data.py
```
Скрипты в папке triggers
triggers.sql
Назначение: SQL‑скрипт, содержащий триггеры для автоматизации бизнес‑процессов в БД.

Список триггеров:

- `update_account_statement` — автоматическое создание выписки при транзакции и обновление баланса счёта.

- `create_loan_schedule` — автоматическое создание графика платежей при добавлении кредита.

- `calculate_deposit_interest` — автоматическое начисление процентов по депозитам.

- `check_overdue_payments` — контроль просроченных платежей (автоматическое изменение статуса на overdue).

- `update_loan_status` — автоматическое обновление статуса кредита при погашении всех платежей.

- `process_loan_payment` — автоматическое списание платежа по кредиту и обновление оставшегося долга.

- `apply_interest_to_account` — автоматическое зачисление процентов на счёт.

- `check_minimum_balance` — контроль минимального баланса счёта (запрет снятия при недостатке средств).

Основная база данных
Bank_DB.db
Описание: основная база данных проекта, создаваемая и заполняемая скриптами из папки scripts.

Таблицы:

- `client` — информация о клиентах банка.

- `user_login` — учётные данные пользователей.

- `account` — банковские счета клиентов.

- `account_transaction` — история транзакций по счетам.

- `loan` — информация о кредитах.

- `deposit` — информация о депозитах.

- `payment_schedule` — график платежей по кредитам и депозитам.

- `account_statement` — выписки по счетам.

- `interest_calculation` — расчёты процентов по депозитам и кредитам.
