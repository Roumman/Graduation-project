# Учебная база данных банковской системы
## Краткое описание компонентов

### Основные файлы
* `README.md` — текущий файл с описанием проекта.
* `LICENSE` — файл с лицензионным соглашением (рекомендуется использовать лицензию MIT).
* `requirements.txt` — список зависимостей Python, необходимых для работы скриптов.
* `.gitignore` — конфигурация для игнорирования временных и служебных файлов в Git.

### База данных (`database/`)
* `create_db.sql` — SQL‑скрипт для создания структуры базы данных (таблицы, индексы, связи).
* `triggers.sql` — реализация триггеров для обеспечения бизнес‑правил и целостности данных.
* `sample_data.sql` — скрипт для заполнения базы тестовыми данными.
* `backup/` — папка для хранения резервных копий базы данных.

### Скрипты (`scripts/`)
* `populate_db.py` — Python‑скрипт для автоматического заполнения базы данных.
* `test_queries.py` — скрипт с тестовыми запросами для проверки работоспособности БД.
* `utils.py` — вспомогательные функции, используемые в других скриптах.

### Учебные материалы (`exercises/`)
* `exercises.json` — JSON‑файл с описанием учебных заданий.
* `solutions/` — папка с эталонными решениями для каждого задания.

### Документация (`docs/`)
* `user_guide.md` — руководство для пользователей проекта.
* `developer_guide.md` — руководство для разработчиков, желающих внести вклад в проект.
* `database_schema.md` — подробное описание схемы базы данных, включая таблицы и их связи.

### Тесты (`tests/`)
* `test_triggers.py` — набор тестов для проверки корректности работы триггеров.
* `test_queries.py` — тесты для проверки учебных SQL‑запросов.

### Примеры (`examples/`)
* `basic_queries.sql` — примеры простых SQL‑запросов для начинающих.
* `advanced_queries.sql` — примеры сложных запросов с использованием JOIN, подзапросов и агрегатных функций.
* `use_cases.md` — описание реальных кейсов использования банковской базы данных.
  
## О проекте

Учебная база данных, моделирующая основные процессы банка:
* управление клиентами и счетами;
* операции с депозитами и кредитами;
* транзакции и выписки;
* бизнес‑правила через триггеры;
* система учебных заданий.

**Цель:** дать практический опыт работы с SQL на примере банковской сферы.

## Особенности

* **Реалистичная схема БД** — отражает настоящие банковские процессы.
* **Автоматизированная бизнес‑логика** через триггеры SQLite.
* **Система учебных заданий** с проверкой решений.
* **Готовые тестовые данные** для начала работы.
* **Примеры запросов** разного уровня сложности.

## Структура базы данных

Основные таблицы:
* `client` — информация о клиентах банка;
* `account` — банковские счета;
* `loan` — кредиты;
* `deposit` — депозиты;
* `account_transaction` — транзакции по счетам;
* `payment_schedule` — графики платежей;
* `bank_branch` — филиалы банка;
* `employee` — сотрудники.

## Установка и запуск

### Предварительные требования
* Python 3.8+
* SQLite 3.30+

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Roumman/Graduation-project
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Создайте и заполните базу данных:
```bash
python scripts/populate_db.py
```
## Использование

### Для обучения SQL

- Откройте `database/create_db.sql` для изучения схемы БД.
- Выполните запросы из `examples/basic_queries.sql`.
- Попробуйте решить задания из `exercises/exercises.json`.

### Для практики с триггерами

- Изучите логику в `database/triggers.sql`.
- Выполните операции, которые активируют триггеры:
  - добавьте транзакцию — проверьте автоматическое обновление баланса;
  - создайте кредит — убедитесь в формировании графика платежей.

### Для преподавателей

Используйте `exercises/` для создания собственных заданий. Формат JSON позволяет легко добавлять новые упражнения.

## Учебные задания

Платформа включает задания трёх уровней:

### Базовый

- простые `SELECT`‑запросы;
- `INSERT` для добавления данных;
- `UPDATE` для изменения записей.

### Продвинутый

- `JOIN` между таблицами;
- агрегатные функции (`SUM`, `COUNT`);
- подзапросы.

### Экспертный

- написание сложных триггеров;
- оптимизация запросов;
- анализ данных.
