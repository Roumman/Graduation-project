# Graduation-project

🏦 О проекте
Данный проект представляет собой тренажёр для имитации работы мобильного банковского приложения. Предназначен для отработки навыков работы с банковскими сервисами: регистрация, авторизация, просмотр баланса, переводы, оплата услуг и т. д.

🔧 Технологии и инструменты
Язык программирования: Python.
База данных: SQLite (для хранения данных пользователей, счетов и транзакций).
Графический интерфейс: Tkinter (для создания окна мобильного банка).
Таблицы БД: client, account, transaction и др. (создаются при первом запуске).
Скрипты: для работы с БД, обработки пользовательских действий, отображения интерфейса.
📥 Установка и запуск
Убедитесь, что у вас установлен Python 3.6+.
Клонируйте репозиторий:
text
git clone https://github.com/ваш_юзернейм/мобильный_банк.git
Перейдите в директорию проекта:
text
cd мобильный_банк
Установите зависимости (если требуется):
text
pip install -r requirements.txt
Запустите основной скрипт:
text
python main.py
🖥️ Функционал тренажёра
Регистрация пользователя (заполнение формы, сохранение в БД).
Авторизация (вход по логину/паролю).
Просмотр баланса счёта.
Переводы между счетами (с проверкой баланса).
Оплата услуг (интернет, телефон, ЖКХ).
История транзакций (отображение последних операций).
Управление профилем (изменение данных, смена пароля).
💾 Структура базы данных
Таблица client
id (PRIMARY KEY) — уникальный идентификатор клиента;
login — логин для входа;
password — хешированный пароль;
full_name — ФИО клиента;
email — электронная почта.
Таблица account
id (PRIMARY KEY) — ID счёта;
client_id (FOREIGN KEY) — ссылка на client.id;
balance — текущий баланс;
currency — валюта счёта (RUB, USD, EUR);
status — статус счёта (активен/заблокирован);
opened_date — дата открытия счёта.
Таблица transaction
id (PRIMARY KEY) — ID транзакции;
account_from (FOREIGN KEY) — счёт отправителя;
account_to (FOREIGN KEY) — счёт получателя;
amount — сумма транзакции;
type — тип операции (перевод, оплата, пополнение);
date — дата и время операции.
💻 Скрипты проекта
db_init.py — создание и инициализация БД.
gui.py — код графического интерфейса (Tkinter).
auth.py — функции авторизации и регистрации.
account_ops.py — операции со счетами (пополнение, переводы).
transaction.py — обработка транзакций и сохранение в БД.
main.py — точка входа в приложение (запускает GUI).
🔎 Примеры использования
Запуск инициализации БД:
text
python db_init.py
Тестирование авторизации:
запустите main.py;
введите логин и пароль тестового пользователя.
Проверка работы с счетами:
после авторизации выберите «Просмотр баланса»;
выполните перевод на другой счёт.
